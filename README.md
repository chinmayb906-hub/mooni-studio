
# 🌙 Mooni Studio — Advanced Episode Engine

Automated children's cartoon story and video generation project.

## Features

- AI-generated original children's stories
- Nine recurring character profiles
- Hindi narration
- Scene-based story generation
- Character-labelled dialogue
- Pixabay video footage
- Automated vertical video rendering
- YouTube Shorts 9:16 format
- GitHub Actions automation
- MP4 video export

## Characters

Golu, Tara, Moti, Dadi, Aarav, Meera, Chiku, Bholu and Uncle Bhola.

## Required GitHub Secrets

- GEMINI_API_KEY
- PIXABAY_API_KEY

## How to generate an episode

1. Open Actions.
2. Select Mooni Studio Advanced Episode Engine.
3. Click Run workflow.
4. Wait for the workflow.
5. Open the completed workflow.
6. Download the mooni-studio-episode artifact.

## Output

- episode.json
- mooni_episode.mp4
- scene audio
- scene video files

## Video format

720 x 1280 vertical video.

## Important

This engine uses AI-generated stories and stock footage.
It is not yet a true 3D character animation engine.
